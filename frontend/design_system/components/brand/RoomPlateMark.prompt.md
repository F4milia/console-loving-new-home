The chosen logo direction — "the room plate": the wordmark set inside a door-number plaque (spruce plate, paper-colored letterspaced type). This is the mark used everywhere a logo would go — header, footer, console top bar, favicon-scale contexts — because the plate itself is the reusable device the rest of the system is built from.

```jsx
<RoomPlateMark />
<RoomPlateMark size="lg" />
```
